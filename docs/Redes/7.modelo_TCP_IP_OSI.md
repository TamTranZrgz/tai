# 7. El modelo TCP/IP y el modelo OSI

El modelo TCP/IP y el modelo de referencia de interconexión de sistemas abiertos (OSI) de ISO. Protocolos TCP/IP.

## El modelo OSI

El modelo OSI (Open Systems Interconnection)

Imagine quiere enviar un paquete internacional. No tiene que saber como en avion vuela, como las aduanas lo chequea, o como el shipper camina al destino. En contrario, solo tiene que envolvelo, redacta la dirección, y deja lo al correro. Cada tarea (envolvo, transporte, aduana, transmitir) es manejado por un departamento, y colaboran con ritmo.

El network también se complica. A ser no un caos, la gente divide el proceso de transmitir data en las capas (layers), cada capa ser responsible de una tarea, y despues la traspasa a la capa seguiente.

El modelo OSI se divide en 7 capas:

- Application
- Presentation
- Session
- Transport
- Network
- Data Link
- Physical
